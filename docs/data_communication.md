# Data Communication

Guided = Physical path like ethernet or a cable
Unguided = Radio waves like WiFi

## Rates of Transmission
Baud rate is the number of signal updates per second
Voltage levels are the number of voltages recorded in the signal not including 0V
the more voltage levels, the more bits required. 


bits per signal = 2 to the power of: bits available for each signal


increase bit rate -> increase bandwidth -> increase number of voltage levels

10 signals/second

= 2x10 = 20 bits/second

bit rate = bits per second
baud rate = signal changes per second

bit rate = baud rate X bits per second

bandwidth = range of frequencies available.
